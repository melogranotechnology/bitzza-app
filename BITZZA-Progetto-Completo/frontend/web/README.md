# BITZZA Wallet frontend

The React/Vite frontend runs against the API at `http://localhost:3000/api` by default.
Set `VITE_API_URL` at build/dev time to change the API base URL; include `/api`.

From this directory:

- `npm run dev` starts the local Vite server.
- `npm run lint` runs Oxlint.
- `npm run build` creates the production bundle in `dist/`.

See the repository [README](../../README.md) for backend setup and the demo-wallet feature scope.
